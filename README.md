# Komentář k zákonu České národní rady č. 62/1988 Sb., o geologických pracích

Otevřený komentář k zákonu o geologických pracích — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; oprávnění k provádění geologických prací, odpovědný řešitel, průzkumná území, projektování, provádění a vyhodnocování geologických prací, geologická dokumentace, kontrola a sankce.

Konsolidované znění: dokument e-Sbírky `SB-1988-00062_2024-01-01`.
